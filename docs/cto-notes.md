# Заметки оператора для ИИ-директора

Файл читается при каждом осмотре (src/cto/observe.js, первые ~4000 символов). Пишите сюда
то, чего нет в метриках: что уже исправлено (с датой), что сделано намеренно, известные
особенности железа. Новое — сверху. Не повторяй предложения по пунктам ниже, пока данные
ПОСЛЕ указанной даты не покажут рецидив.

## 2026-10-13 — исправлено и выкачено
- Падения процесса `ERR_INTERNAL_ASSERTION` (HTTP-клиент Node, 02:27 и 07:47 UTC): теперь не роняют процесс,
  в журнале событие `http_parser_assert`. Рецидив = новые `http_parser_assert`/`uncaught_exception` ПОСЛЕ 09:00 UTC.
- Лаги event loop 45–58 с: причина — публичная страница статуса (полный скан modem_ping на каждый визит), починено кэшем;
  лаги 4–5 с — синк журнала ротаций (теперь инкрементальный); 12 с в 02:00 UTC — проверка бэкапа (вынесена в поток);
  3–4 с в 05:00 UTC — контекст утренней сводки (вынесен в поток). Рецидив = `eventloop_lag` с max > 2000 мс ПОСЛЕ 13:00 UTC.
- Фантомный трафик (дневной счётчик провалился среди дня без смены «вчера» → в час писались целые прошлые сутки):
  логика сброса дня исправлена, сомнительное падение откладывается на опрос (событие `traffic_day_drop_held`).
  Старые фантомные часы в истории НЕ вычищаем (решение владельца: ПАЛИТРУМЛАБ не компенсируем).
- Модемы без клиента исключены из всей статистики (ротации, пинги, HTTP, спидтесты не считаются); у них автоматически
  выключается авторотация (правило IdleModemRotation) — иначе бокс S4 перезагружал их вхолостую и блокировал панель.
  MD_17/18/19 (S4) и MD_81–87 (S3) — свободные модемы с SIM без сети, это известно.
- Облачная выгрузка бэкапов выключена намеренно (`BACKUP_OFFSITE=off`): у владельца свой автобэкап сервера.
- Расписание `reset_gently` на S4 — каждые 15 минут (было `*/5` до 03.10), после выключения ротации у MD_17–19 прогон 3 с.

## Известные особенности
- Спидтесты S1/S4/RO1 ночью (01:00–05:00 МСК) падают с пустым результатом (общий внешний сервис спидтеста), S3 — нет. Починить можно только на боксах.
- RO1_32 и MD_49 (S3): клиентские модемы, у которых IP не меняется (стабильно ~100% неуспешных ротаций).
- Vodafone RO по норме меняет IP редко (порог 80%).
- Платформа: ProxySmart, скрипты боксов обфусцированы — о причинах внутри них говорим как о гипотезах.
