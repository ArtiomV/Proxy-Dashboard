# Публичная страница статуса

Источник истины для `https://arendaproxy.ru/status/`:

```text
GET https://app.arendaproxy.ru/api/public/status
```

Endpoint открыт только на чтение, разрешает CORS и отдаёт агрегаты по странам без IP, IMEI, клиентов и реквизитов. Данные Молдовы и Румынии считаются из нативного `ProxySmart net_details.ping_stats`; окно свежести — 10 минут, uptime — 60 дней.

Соответствие блоков страницы:

- `residential-ru` → «Резидентские прокси РФ»;
- `mobile-md` → «Мобильные прокси Молдовы»;
- `mobile-ro` → «Мобильные прокси Румынии».

`status`: `operational`, `degraded`, `major_outage`, `unknown`. Для `unknown` сайт должен показывать «Нет данных», а не `100%`. Массив `days` используется для 60-дневной полосы доступности. Поле `updatedAt` — фактическое время обновления заголовка страницы.

Готовый drop-in адаптер под текущую DOM-структуру страницы лежит в `integrations/arendaproxy/statuses.js`. Им нужно заменить текущий `/js/statuses.js` в репозитории/хостинге `arendaproxy.ru`. Адаптер снача сбрасывает статические 100% в «Нет данных», а затем заполняет карточки ответом API.

Пока телеметрия резидентского пула не подключена, `residential-ru` честно возвращается как `unknown`.
